## 1. 背景与问题

会话界面的正文字号当前固定在 13pt、输入框固定 11pt，由 CSS/样式表硬编码。不同屏幕尺寸、缩放比例和阅读习惯的用户难以舒适地阅读长回答；大屏或远程桌面下字号可能过小，笔记本小屏下又可能过大。

本需求让用户在不修改主题、不重启应用的前提下调整会话字号，并记住选择。

## 2. 目标与非目标

### 2.1 目标

- G1：设置页可调节会话字号，带实时预览，默认值与当前视觉一致。
- G2：保存后立即作用于已打开的会话界面，无需重启。
- G3：字号选择持久化到 `config.json`，重启后保持。
- G4：非法值、缺失值或损坏配置回退默认，不导致界面异常。
- G5：调整字号不丢消息、输入草稿、会话可见性与阅读位置。
- G6：角色标签（Agent/你/系统）始终比正文大，层级清晰。
- G7：会话历史中的图片缩略图宽度可调，并与字号一样即时生效、持久化。

### 2.2 非目标

- 不调整截图标注遮罩、回答完成通知、托盘菜单等非会话界面字号。
- 不提供按会话、按后端分别保存字号；字号是全局设置。
- 不提供主题切换、行高、字体家族或等宽字体设置。
- 不新增调节字号的快捷键；入口仅设置页。
- 不改变截图表单、会话标题、模型选择器与按钮的字号。
- 图片预览对话框仍按屏幕可用区域缩放，不受历史缩略图宽度限制。

## 4. 功能需求

### FR-1 设置入口与范围（P0）

- 托盘菜单「设置…」中新增「会话显示」分组，包含字号与图片宽度两项。
- 字号控件为整数选择（spin box），范围 `9–24 pt`，步长 1，默认 `13 pt`。
- 字号控件旁展示实时预览文本，预览字号随控件值变化。
- 图片宽度控件为整数选择（spin box），范围 `160–1200 px`，步长 20，默认 `360 px`。
- 控件展示当前生效值；首次运行或旧配置缺失时显示默认值。
- 「恢复默认」同时把字号恢复为 13、图片宽度恢复为 360，不影响截图热键、存储位置与输入快捷键。

### FR-2 字号生效范围（P0）

- 应用于会话历史正文：Agent 回答（含 Markdown 渲染）、用户消息、系统/错误消息。
- 应用于会话底部输入框文本；输入框高度随字号增长，最小保持现有 68px，避免文字被裁切。
- 角色标签（Agent/你/系统）固定为 `字号 + 2 pt`，必须始终大于正文字号；空态提示按 `max(9, 字号-3) pt` 派生。
- 历史消息中的图片缩略图宽度使用 `conversation.image_width`（见 FR-6），默认 360px。
- 以下保持不变：标题、模型选择器、会话元信息、提示文案、按钮、窗口透明度与布局边距。
- 字号只影响显示，不改变消息内容、Markdown 解析结果、附件路径或发送给 Agent 的文本。

### FR-3 即时生效与状态保持（P0）

- 设置在设置页点击「保存」成功后立即应用到当前会话界面。
- 应用字号或图片宽度只重绘历史与输入框样式：
  - 不追加、不删除、不重新请求消息；
  - 输入草稿保留；
  - 会话若隐藏则保持隐藏，若可见则保持可见；
  - 尽量保持当前滚动位置；若内容高度变化导致位置越界，钳制到新范围。
- 流式生成期间允许修改字号：重绘不得中断流式更新；后续增量继续写入同一条 Agent 消息。

### FR-4 校验、持久化与回退（P0）

- 配置新增：
  - `conversation.font_size`（整数，单位 pt）；
  - `conversation.image_width`（整数，单位 px）。
- 保存时写入 `%APPDATA%\ScreenToAgent\config.json`，保留文件中其他字段。
- 加载时：
  - 字号缺失 → 默认 13；非数字 → 默认 13；小于 9 → 按 9；大于 24 → 按 24。
  - 图片宽度缺失 → 默认 360；非数字 → 默认 360；小于 160 → 按 160；大于 1200 → 按 1200。
- 设置页保存失败（写配置异常等）时：
  - 明确提示失败原因；
  - 保留旧字号、旧图片宽度与旧配置，不部分生效。
- 修改字号或图片宽度不需要重新注册热键，也不影响热键、后端、模型、存储位置与输入快捷键。
- 字号与图片宽度不写入日志，不属于敏感信息。

### FR-5 兼容性（P0）

- 旧版本 `config.json` 没有 `conversation` 字段时按默认值运行，不要求升级配置。
- API 模式与 Codex CLI 模式共用同一字号与图片宽度设置。
- 会话隐藏、重新显示、切换会话或重新加载历史后，字号与图片宽度保持当前配置值。

### FR-6 会话图片大小（P0）

- 设置页「会话显示」新增「图片宽度」控件，范围 160–1200px，步长 20，默认 360。
- 仅调整会话历史中图片缩略图的显示宽度；高度按原图比例缩放。
- 图片仍可点击打开预览；预览对话框按屏幕可用区域缩放，不受缩略图宽度限制。
- 调整后立即重绘历史消息，不重新加载图片文件、不改变附件路径；缺失图片继续显示“图片不可用”。
- 图片宽度不影响发送给 Agent 的图片内容或分辨率。

## 5. 交互流程

1. 用户打开托盘菜单 →「设置…」。
2. 在「会话显示」中把字号从 13 调整为 18，预览文本立即变大。
3. 把图片宽度从 360 调整为 520。
4. 点击「保存」。
5. 设置写入配置；若会话已打开，历史正文与输入框立即变为 18pt，角色标签变为 20pt，图片缩略图变为 520px 宽，滚动位置尽量保持。
6. 关闭并重新启动应用，再次打开会话仍为 18pt 与 520px。

异常流程：

- 配置写入失败 → 状态栏红字提示，设置页不关闭，旧字号与旧图片宽度继续生效。
- 手工把字号改成 `30` 或 `"abc"` → 启动后分别按 24 和默认 13 处理。
- 手工把图片宽度改成 `9999` 或 `"abc"` → 启动后分别按 1200 和默认 360 处理。

## 6. 配置示例

```json
{
  "conversation": {
    "font_size": 18,
    "image_width": 520
  }
}
```

说明：

- `font_size` 单位是 pt，与 Qt 样式表中的 `pt` 一致；允许范围 9–24，超出范围在加载时钳制。
- `image_width` 是历史图片缩略图宽度，单位 px；允许范围 160–1200，超出范围在加载时钳制。
- 未提供字段时分别视为 13 与 360。

## 8. 验收标准

- AC-01：设置页存在「会话显示」分组，字号范围 9–24、默认 13，预览随值变化；图片宽度范围 160–1200、默认 360。
- AC-02：保存字号 18 后，已打开会话的历史正文与输入框立即按 18pt 显示，角色标签按 20pt 显示，无需重启。
- AC-03：重启应用后字号与图片宽度保持；旧配置无对应字段时按 13 与 360 运行。
- AC-04：字号小于 9 按 9、大于 24 按 24、非数字按 13；图片宽度小于 160 按 160、大于 1200 按 1200、非数字按 360。
- AC-05：调整字号或图片宽度不会清空消息、输入草稿、命令输入，也不改变会话可见性。
- AC-06：字号变更不影响截图标注遮罩、标题、模型选择器与按钮字号；角色标签始终大于正文。
- AC-07：保存配置失败时提示失败，旧字号、旧图片宽度与旧配置保持不变。
- AC-08：保存图片宽度 520 后，历史图片缩略图立即按 520px 宽显示且保持宽高比；点击仍可预览。
- AC-09：相关自动化测试通过，`ruff check` 无错误。

## 9. 风险与开放问题

| 编号 | 风险/问题 | 处理建议 |
| --- | --- | --- |
| R-1 | 过大的字号导致单屏内容过少 | 上限 24pt；滚动与 PageUp/PageDown 仍可阅读。 |
| R-2 | 重绘导致阅读位置跳动 | 重绘前记录滚动值，重绘后钳制恢复。 |
| R-3 | 流式期间重绘与增量更新竞争 | 重绘只读取当前内存消息，不重置流式状态；增量继续更新最后一条消息。 |
| R-4 | 输入框高度随字号增长挤压历史区域 | 高度上限按 24pt 计算（约 96px），历史区域使用伸缩布局。 |
| R-5 | 图片宽度超过小屏可用宽度导致横向滚动 | 上限 1200px；`QTextBrowser` 在窗口较窄时可横向滚动，用户可调小。 |
| R-6 | 角色标签加大会占用更多垂直空间 | 仅 +2pt，且标签为单行，影响可接受。 |
| Q-1 | 是否增加 `Ctrl+滚轮` 快速调节？ | 不在本需求范围；可后续单独评估。 |
| Q-2 | 是否支持分别设置历史与输入框字号？ | 否；单一字号更简单，避免设置项膨胀。 |
| Q-3 | 是否调整回答完成通知字号？ | 否；受系统通知控制，不在应用内。 |
| Q-4 | 图片宽度是否跟随字号自动缩放？ | 否；两者独立配置，避免用户只想改字号时图片意外变化。 |

## 11. 当前实现说明（0.3）

已实现：

- `conversation.font_size` 配置项，默认 13，加载时钳制到 9–24，非法值回退 13。
- `conversation.image_width` 配置项，默认 360，加载时钳制到 160–1200，非法值回退 360。
- 设置页「会话显示」提供字号（9–24pt，带实时预览）与图片宽度（160–1200px）控件，支持「恢复默认」。
- 会话历史正文、角色标签、空态提示与底部输入框按字号渲染；角色标签固定比正文大 2pt；输入框高度自动调整。
- 历史图片缩略图按 `image_width` 显示并保持宽高比，点击仍打开屏幕自适应预览。
- 保存后立即重绘已打开会话并尽量保持滚动位置；不丢消息、草稿与会话可见性。
- 保存失败时提示原因并保留旧配置；字号与图片宽度不影响热键、存储位置与输入快捷键。

当前限制：

- 字号与图片宽度为全局设置，不支持按会话或按后端区分。
- 不提供滚轮/快捷键快速调节。
- 标题、模型选择器、按钮与截图标注界面不随字号变化。
